# Build Rules

## Stack Contract

- Vite
- React
- TypeScript
- Tailwind
- Framer Motion
- Lucide React

## Constraints

- Do not add unnecessary dependencies
- Keep this as a one-page microsite
- Centralize editable content in `src/data/resumeData.ts`
- Keep motion reusable and minimal
- Preserve GitHub Pages compatibility in every asset path decision

## Build Checklist

- `npm install`
- `npm run build`
- Fix all build errors before handoff
